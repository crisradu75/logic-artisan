The exit-2-on-empty row is load-bearing: a scan run from the wrong directory otherwise reports "0 violations" over a tree it never read — the same shape `CLAUDE.md` records for the ledger-dir resolver, *"the retro reports zero runs, which reads as a cold start."*

- [ ] 2.6 Write the mutant batch at `plugin-tests/mutants/test_check_shipped_tree.py`. `CLAUDE.md`'s rule 4 requires the full four checks for a new script, and this is the one that proves the tests can fail. **Mutate what the scan *touches*, not only what it targets** — user memory records three green-but-broken ships from a corpus containing only the targeted case. - [ ] 2.7 Run the batch and record survivors. A survivor is a finding, not a formality — and per `CLAUDE.md`, a clean run is evidence about the mutants you thought of and nothing else, so record it as one input rather than as the ship decision.
