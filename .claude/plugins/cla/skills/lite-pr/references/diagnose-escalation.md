# Escalating a stalled Test phase to /cla:diagnose (moved from Test step 3 of SKILL.md; "here" and "step 4" mean SKILL.md's Test phase)

**One fix and one retry on the SAME stated cause with the gate still red → stop editing and escalate to `/cla:diagnose`** — a fix that did not turn the gate green is the signal the hypothesis is wrong, and this is the one budget: on the same cause, step 4's HALT comes after this escalation, not instead of it. `diagnose` builds a deterministic pass/fail loop and ranks falsifiable hypotheses before touching anything, which is the step a second edit skips. **How to escalate depends on whether anyone is there to answer, and this run has two callers.** Invoked by the user → *offer* it, and hand the failure back if they decline. Invoked by `/cla:multi-lite` — a long unattended run whose whole point is that the user can walk away, with no mid-chain pauses — → invoke `Skill(cla:diagnose)` directly and say in the invocation that it runs unattended; never put a question mid-chain to a user who is not there. Either way `diagnose` reports its ranked hypotheses, so the reasoning survives for the user who reads the run afterwards. **Run from this Test phase, `diagnose` commits nothing, on either arm.** Nothing is committed in Test and the feature branch does not exist until Ship, so a `diagnose` commit would land on the base branch. Say so in the invocation: it leaves its fix and its regression test UNCOMMITTED in the working tree, skipping its own commit step; Ship commits them on the feature branch, and the confirmed cause goes into Ship's commit message instead. **Its outcome feeds back here, and it does NOT buy a fresh retry.** A confirmed cause with its fix applied → re-run the failing tier once: green proceeds to Ship, still red falls to step 4. A `diagnose` that ends any other way — no buildable loop, no correct seam, every hypothesis falsified, a loop that reproduces a different failure, or a halt on leftover debug tags — goes straight to step 4 carrying that finding (and the `cla.io/feedback/` note, where it wrote one), never another edit round. Saying this matters most on the unattended arm: without it the nearest applicable rule is step 4's HALT, so a candidate `diagnose` had just FIXED would halt anyway, and `/cla:multi-lite` would quarantine it along with everything downstream of it.
